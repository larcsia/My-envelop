# My Envelop 💌

Create and send personalized, interactive digital envelopes to your friends. Customize colors, stamps, and wax seals, add attachments, and share via a unique link.

## ✨ Features
- **Customizable Design:** Change envelope, paper, text, and wax seal colors.
- **Attachments:** Add images from your device or paste links (YouTube, Spotify, Apple Music, Audio).
- **Realistic Wax Seal:** Toggle a beautifully designed SVG wax seal.
- **Custom Stamps:** Upload your own stamp and position it anywhere.
- **Secret Links:** Generates a unique, shareable link for each envelope.
- **Responsive:** Works seamlessly on mobile and desktop.

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Database:** Firebase Firestore (for saving envelope data)
- **Authentication:** Firebase Anonymous Auth
- **Image Hosting:** Cloudinary

## 📝 How to Use
1. Open the live website.
2. Customize your envelope (colors, message, attachments).
3. Click **Copy Link**.
4. Send the generated link to your friend. They will see a sealed envelope that they can click to open!
